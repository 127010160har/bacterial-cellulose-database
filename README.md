Bacterial Cellulose Production Research Database

Project Overview

This project develops a research database and interactive analytics dashboard for bacterial cellulose (BC) production. It organizes research data from scientific publications and helps users explore production conditions, bacterial strains, yields, and material properties.

Objectives

- Collect and organize bacterial cellulose research data.
- Store experimental information in an SQLite database.
- Compare bacterial strains and carbon sources.
- Analyse bacterial cellulose production yields.
- Visualize research findings through an interactive dashboard.

Technologies Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- SQLite
- Streamlit
- Plotly
- GitHub

Main Features

- Interactive research dashboard
- Bacterial strain and culture condition filters
- Yield analysis and visualizations
- Material property analysis
- Research data table
- CSV data download

Project Structure

- "app.py" – Streamlit dashboard application
- "bacterial_cellulose.db" – SQLite research database
- "requirements.txt" – Required Python packages
- "README.md" – Project documentation
