Bacterial Cellulose Production Research Database

A research database and interactive dashboard for exploring bacterial cellulose production.

Project Objectives

- Collect bacterial cellulose research data.
- Organize experimental results.
- Compare bacterial strains and carbon sources.
- Analyse production yield and material properties.

Technologies Used

- Python
- Pandas
- SQLite
- Streamlit
- Plotly
- Matplotlib

Features

- Interactive research dashboard
- Database filters
- Production yield analysis
- Research data visualization
- Downloadable research data

Project Files

- "app.py" – Dashboard application
- "bacterial_cellulose.db" – Research database
- "requirements.txt" – Required Python libraries

Future Scope

- Add more research publications.
- Expand the experimental dataset.
- Improve statistical analysis and visualizations.
